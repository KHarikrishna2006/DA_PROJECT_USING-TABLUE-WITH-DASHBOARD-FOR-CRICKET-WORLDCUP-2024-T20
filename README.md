
# 🏏 ICC T20 World Cup 2024 Performance Analytics Dashboard

## 📌 Project Overview

This project is an interactive Tableau dashboard built to analyze the performance of teams, players, venues, and match strategies in the ICC Men's T20 World Cup 2024.

The objective of this project is to transform raw cricket data into meaningful insights using Tableau visualizations and dashboards.

## 📂 Dataset

The dataset contains match-level information such as:

- Teams
- Venue
- Toss Winner
- Toss Decision
- First Innings Score
- Second Innings Score
- Highest Individual Score
- Match Winner
- Player Details

---

## 🧹 Data Cleaning

Before importing the dataset into Tableau, the data was cleaned using Microsoft Excel.

The following preprocessing steps were performed:

- Removed duplicate records
- Handled missing values
- Corrected inconsistent team names
- Standardized venue names
- Removed unnecessary columns
- Fixed data formatting issues
- Verified numerical columns for analysis
- Saved the cleaned dataset as **ICC Mens T20 Worldcup Cleaned.csv**

---

## 📊 Dashboard KPIs

The dashboard displays the following Key Performance Indicators (KPIs):

- Total Matches
- Average First Innings Score
- Average Second Innings Score

---

## 📈 Dashboard Visualizations

### 1. Average First and Second Innings Score per Venue

Shows how batting performance varies across different stadiums.

**Insight**
- Identifies batting-friendly and bowling-friendly venues.

---

### 2. Top Highest Scores

Displays the players with the highest individual scores in the tournament.

**Insight**
- Highlights the tournament's top-performing batsmen.

---

### 3. Toss Decision Distribution

Shows the number of teams choosing:

- Bat First
- Field First

**Insight**
- Most captains preferred fielding after winning the toss.

---

### 4. Average Highest Score Based on Toss Decision

Compares the average highest individual score between teams choosing to bat first and field first.

**Insight**
- Helps analyze whether toss decisions influence batting performance.

---

## 🔍 Key Insights

- The average first innings score is higher than the average second innings score.
- Most teams preferred to field after winning the toss.
- Some venues consistently produced higher-scoring matches.
- A few players dominated the tournament with exceptional individual scores.
- Toss decisions may influence batting outcomes but do not solely determine match performance.
